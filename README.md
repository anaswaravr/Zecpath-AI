# ZECPATH-AI

## Overview

ZECPATH-AI is a modular AI project created as part of the Zecpath AI Training Program. The project follows a structured folder organization and includes logging, testing, and version control setup.

---

## Project Structure

```
ZECPATH-AI/
│── ats_engine/
│── interview_ai/
│── parsers/
│── scoring/
│── screening_ai/
│── tests/
│── utils/
│── logs/
│── main.py
│── requirements.txt
│── README.md
│── .gitignore
```

---

## Features

- Modular project structure
- Virtual environment setup
- Logging system
- Unit testing using Pytest


---

## Installation

```bash
git clone https://github.com/anaswaravr/Zecpath-AI.git

cd Zecpath-AI

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt
```

---

## Run

```bash
python main.py
```

Run Logger

```bash
python utils/logger.py
```

Run Tests

```bash
pytest
```
